Embedded & FPGA platform

Tron light cycle game

A Tron-inspired light cycle game running on a DE10-Lite FPGA development board.

My workGame logic and bare-metal peripheral drivers
Tools & hardwareC · DE10-Lite · Memory-mapped I/O
InputsPushbuttons + speed switches
C game logicMovement, state, and scorekeeping
OutputsHEX score displays

Game controls

I implemented the game in C, using pushbuttons for player controls and switches for speed selection. The game tracks player and non-player wins and displays scores on the board’s HEX outputs.

Working with the board

I wrote bare-metal C drivers to access the peripherals through memory-mapped I/O. The project brought together input handling, game-state updates, and score-display routines on the same platform.
