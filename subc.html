SUBC steering & sensor logging

I work with UBC’s SUBC electrical team on sensor logging, board testing, and steering-control development.

My workFirmware, PCB assembly & validation
Tools & hardwareC · I2C · SPI · SD logging · PID

Sensor logging

I developed a modular C framework for high-volume I2C sensor acquisition and SPI-based SD card storage. It supports collecting trial data over longer runs so the team can compare performance afterward.

Board testing

My hands-on work includes soldering custom PCBs, checking continuity, probing power rails with a multimeter, and writing firmware test scripts to help isolate faults.

Steering control — in progress

I’m working on a PID-based steering-control loop using physical joystick position as an input. This is ongoing development rather than a completed, validated control system.
