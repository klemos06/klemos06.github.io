Reflow oven controller

A toaster oven controlled through a reflow profile using temperature feedback and 8051 assembly firmware.

Temperature measurement

The sensing circuit uses a thermocouple, op-amp amplification, an LM335 temperature sensor, and an LM4040 voltage reference for cold-junction comparison. A moving-average filter smooths the readings used by the controller and display.

Reflow control

I wrote 8051 assembly firmware for a CV-8052 soft processor. Interrupt-based PWM drives the solid-state relay as the oven progresses through the reflow states. The GUI lets the user set cycle parameters and view temperature and duty-cycle plots.
